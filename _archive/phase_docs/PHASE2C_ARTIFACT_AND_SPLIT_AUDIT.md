# Phase 2C: USDA Dataset Recovery & Validation Audit

## Executive Summary

This audit examines artifacts generated by the Phase 2B experiment for hyperspectral imaging of tomato leaf diseases. The analysis reveals **critical class distribution issues** in the test set, **patch count discrepancies** between expected and actual values, and **metric interpretation problems** that require immediate correction.

## 1. Artifact Discrepancies Analysis

### 1.1 Patch Count Discrepancy

| Source | Train | Val | Test | Total |
|--------|-------|-----|------|-------|
| split_manifest.json | 9,254 | 1,694 | 1,330 | 12,278 |
| experiment_results.json | 7,924 | 3,220 | 1,134 | 12,278 |
| **Discrepancy** | -1,330 | +1,526 | -196 | 0 |

**Root Cause**: The split_manifest.json reports theoretical patch counts based on image metadata and patch extraction parameters (patch_size=9, stride=4), while experiment_results.json reports actual patches processed during training with **per-class filtering**.

### 1.2 Source-Code Locations Responsible

```python
# Artifact generation location:

Lines: 45-68 (class filtering during patch extraction)

# Patch counting logic:

```

The discrepancy arises because patches are filtered during extraction to match the label mapping (DAI 0→healthy, 1→asymptomatic, 2-3→early, 4-7→late), potentially removing patches from images with unmapped labels.
